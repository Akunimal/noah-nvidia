# English demo script — under three minutes

Use the connected Nebius/NVIDIA path for the natural-language extraction shot
only when the operator has verified the private key, model, quota, and manual
Render configuration. Otherwise use the public synthetic path and say so
explicitly. Never show a secret, a private prompt, or a raw provider response.

## 0:00–0:20 — The problem

“Small service businesses have work scattered across conversations, mail,
calendar, and spreadsheets. Noah turns a plain-language request into
reviewable work while keeping the owner in control.”

## 0:20–0:45 — Safe public entry

Open the English Noah Nvidia console. Point to the `PUBLIC RUNTIME` panel and
say: “The public URL is bounded. Before the scheduled window it uses a
synthetic sandbox; if promotional credit is unavailable, the same fallback
remains usable and is labeled honestly.”

## 0:45–1:25 — Onboarding and structured context

Choose **Start setup** and enter a short business description, for example:
“We are North Workshop. We maintain industrial equipment for local factories
and keep filters and pumps in stock.” Choose **Build draft**. Show the editable
business fields, optional inventory, strict `onboarding.v1` JSON, missing-field
list, and the provenance line. Say: “NVIDIA Nemotron prepares a draft; it does
not write business data before review.”

If the connected route is unavailable during recording, choose **Complete
manually** and show the same schema. Do not imply that manual mode used a
model.

## 1:25–1:50 — Human decision

Correct one field if needed, then choose **Confirm setup**. Show the success
state and say: “Only the explicit confirmation applies the reviewed snapshot;
the operation is idempotent and tenant-scoped.”

## 1:50–2:20 — Supervised work

Enter the playground, submit a harmless synthetic request, and show a typed
proposal in Approvals. Explain that Gmail, Calendar, payments, and other
external effects remain behind approval and a verifiable receipt. Do not
execute a real external effect in the video.

## 2:20–2:45 — Skip and safety fallback

Return to a fresh browser or use the public path. Choose **Skip and explore**,
then **I understand, skip**. Show the Atlas Services warning and say: “Skip
does not pretend to understand a real company; it loads fictional data for
exploration only.”

## 2:45–3:00 — NVIDIA attribution and close

“Nebius Token Factory is the connected route for NVIDIA Nemotron. NVIDIA
embeddings, reranking, Parse, NeMo Agent Toolkit, and Guardrails have explicit
adapter boundaries. OpenCode2API is only a synthetic NVIDIA-only test
transport and is disabled in the public Render configuration. The code,
tests, Promptfoo evidence, and release checks are public.”
