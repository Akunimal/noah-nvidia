# Contract evaluation cases

The acceptance plan calls for a reviewable set of synthetic cases across mail,
calendar, administration, knowledge, hostile instructions, and composite work.
The JSON fixture in this directory is intentionally provider-neutral: it checks
authority and expected tool boundaries without pretending to measure Nemotron
quality when no model key is configured.

Connected evaluation runs should record the provider, model, latency, token
usage, proposed actions, blocked actions, and evidence receipts beside each
case. Sandbox runs must remain labeled synthetic.
